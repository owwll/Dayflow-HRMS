# Cloudinary Image Management Guide

## 🎯 How to View Uploaded Images on Cloudinary

### Step 1: Access Cloudinary Dashboard

1. **Go to Cloudinary:** https://cloudinary.com
2. **Login** with your account credentials
3. You'll land on the **Dashboard** page

---

### Step 2: Navigate to Media Library

1. Click on **"Media Library"** in the left sidebar
2. Or go directly to: https://console.cloudinary.com/console/media_library

---

### Step 3: Browse Your Uploaded Images

You'll see all your uploaded files organized by folders:

```
📁 hrms/
  📁 profiles/          ← Profile pictures
    📄 profile_user_123.jpg
    📄 profile_user_456.jpg
  📁 leave-attachments/ ← Leave request attachments
    📄 attachment_xyz.pdf
    📄 medical_cert.jpg
```

---

## 🔍 Finding Specific Images

### By Folder Structure

Our backend uploads images to specific folders:

1. **Profile Pictures:** `hrms/profiles/`
   - Named as: `profile_{userId}`
   - Example: `profile_clx123abc456.jpg`

2. **Leave Attachments:** `hrms/leave-attachments/`
   - Random names generated by Cloudinary
   - Example: `abc123xyz456.pdf`

### Using Search

1. Click the **Search** icon (🔍) in Media Library
2. Search by:
   - **Folder name:** `hrms/profiles`
   - **File name:** `profile_`
   - **Tag:** (if you add tags in the future)
   - **Upload date:** Filter by date range

## 📊 Image Details & Information

### View Image Details

1. **Click on any image** in the Media Library
2. A panel will open on the right showing:
   - **Preview** of the image
   - **Public URL** (the URL stored in your database)
   - **File size**
   - **Dimensions** (width x height)
   - **Format** (JPG, PNG, PDF, etc.)
   - **Upload date**
   - **Folder path**

### Copy Image URL

1. Click on the image
2. In the right panel, find **"Public URL"**
3. Click the **Copy** icon next to the URL
4. This is the same URL stored in your database as `profilePicUrl`

**Example URL:**
```
https://res.cloudinary.com/your-cloud-name/image/upload/v1234567890/hrms/profiles/profile_user_123.jpg
```

## 🔗 Getting Image URLs

### Direct URL from Dashboard

1. Click on the image
2. Copy the **Public URL** from the right panel

### URL Format

Cloudinary URLs follow this pattern:
```
https://res.cloudinary.com/{cloud_name}/{resource_type}/{type}/v{version}/{folder}/{filename}
```

**Example:**
```
https://res.cloudinary.com/dayflow-hrms/image/upload/v1735891234/hrms/profiles/profile_clx123.jpg
```

**Parts:**
- `dayflow-hrms` - Your cloud name
- `image` - Resource type (image/video/raw)
- `upload` - Delivery type
- `v1735891234` - Version timestamp
- `hrms/profiles/` - Folder path
- `profile_clx123.jpg` - Filename

## 🎨 Image Transformations

Cloudinary allows you to transform images on-the-fly by modifying the URL:

### Resize Image
```
https://res.cloudinary.com/your-cloud/image/upload/w_200,h_200,c_fill/hrms/profiles/profile_user_123.jpg
```
- `w_200` - Width 200px
- `h_200` - Height 200px
- `c_fill` - Crop mode

### Create Thumbnail
```
https://res.cloudinary.com/your-cloud/image/upload/w_150,h_150,c_thumb/hrms/profiles/profile_user_123.jpg
```

### Apply Effects
```
https://res.cloudinary.com/your-cloud/image/upload/e_grayscale/hrms/profiles/profile_user_123.jpg
```

### Quality Optimization
```
https://res.cloudinary.com/your-cloud/image/upload/q_auto,f_auto/hrms/profiles/profile_user_123.jpg
```
- `q_auto` - Auto quality
- `f_auto` - Auto format (WebP for supported browsers)

## 🗑️ Delete Images

### Delete Single Image

1. Click on the image
2. Click the **Delete** button (🗑️) in the right panel
3. Confirm deletion

**⚠️ Warning:** Deleting from Cloudinary won't update your database. The URL will still be stored but will return 404.

### Delete Multiple Images

1. Select images using checkboxes
2. Click **"Delete"** button at the top
3. Confirm deletion

### Delete Folder

1. Right-click on the folder
2. Select **"Delete folder"**
3. Confirm (this deletes all images inside)

---

## 🔐 Security & Access Control

### Make Images Private

1. Click on the image
2. In the right panel, click **"Access Control"**
3. Change from **"Public"** to **"Authenticated"**
4. Now the image requires authentication to view

### Generate Signed URLs

For sensitive documents, you can generate time-limited signed URLs in your backend code:

```javascript
import cloudinary from '../config/cloudinary';

const signedUrl = cloudinary.url('hrms/profiles/profile_user_123.jpg', {
  sign_url: true,
  type: 'authenticated'
});
```

## 🔄 Sync with Database

### Check if Image Exists

When viewing a user profile in your app, the `profilePicUrl` field contains the Cloudinary URL.

**Example from database:**
```json
{
  "profilePicUrl": "https://res.cloudinary.com/your-cloud/image/upload/v1735891234/hrms/profiles/profile_clx123.jpg"
}
```

### Verify Image is Accessible

1. Copy the URL from your database
2. Paste it in a browser
3. The image should load

If you get a 404 error:
- Image was deleted from Cloudinary
- URL is incorrect
- Image is set to private/authenticated

## 🛠️ Useful Cloudinary Features

### Auto-Backup

1. Go to **Settings** → **Upload**
2. Enable **"Auto-backup"**
3. Cloudinary will keep backups of deleted images for 30 days

### Upload Presets

1. Go to **Settings** → **Upload**
2. Click **"Add upload preset"**
3. Configure default settings for uploads
4. Use preset name in your backend code

### Webhooks

1. Go to **Settings** → **Webhooks**
2. Add webhook URL to get notified when:
   - Images are uploaded
   - Images are deleted
   - Transformations are applied

## 🧪 Testing Image Upload

### Test Profile Picture Upload

**Endpoint:** `POST /api/v1/profile/{userId}/upload-picture`

**In Postman:**
1. Select **Body** → **form-data**
2. Key: `profilePic`, Type: **File**
3. Select an image (JPG/PNG)
4. Add header: `Authorization: Bearer {accessToken}`
5. Send request

**Response:**
```json
{
  "success": true,
  "data": {
    "profilePicUrl": "https://res.cloudinary.com/your-cloud/image/upload/v1735891234/hrms/profiles/profile_clx123.jpg"
  }
}
```

**Verify on Cloudinary:**
1. Go to Media Library
2. Navigate to `hrms/profiles/`
3. You should see the newly uploaded image

## 🆘 Troubleshooting

### Image Not Showing in Media Library

**Possible causes:**
- Upload failed (check server logs)
- Wrong folder path
- Cloudinary credentials incorrect

**Solution:**
- Check `.env` file for correct Cloudinary credentials
- Verify upload was successful in API response
- Check server logs for errors

### 404 Error When Accessing Image URL

**Possible causes:**
- Image was deleted
- URL is incorrect
- Image is set to private

**Solution:**
- Check if image exists in Media Library
- Verify URL matches the one in database
- Check image access control settings

### Upload Quota Exceeded

**Solution:**
- Upgrade your Cloudinary plan
- Delete unused images
- Optimize image sizes before upload
